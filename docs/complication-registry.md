# 并发症登记册（唯一事实源 · v0 初版）

- 建立：2026-11-18，依据《并发症工作台产品线立项评估》（2026-11-18，Codex/sam2，结论：有条件做）与用户 2026-11-18 21:41 拍板（消化道出血排入队列、位于脑梗死之后，先补登记册前置）。
- 用途：并发症方向的唯一登记与去重闸门。任何并发症新仓/新模块开工前，必须先查本册 + 全组织仓库列表 + Issue 搜索 + 别名核对；状态为 unknown/stale 的条目一律视为「不得建新仓」，先人工核实。
- 落位计划：本地为初版存档；消化道出血启动前，由流水线看守将本册落入组织 `.github` 仓 `docs/complication-registry.md` 并 commit+push，此后以仓内版本为事实源、本地为镜像。
- 状态机：`proposed → researching → approved → active → released → retired`；另有 `split-required`（总题太宽、不可直接交付，须拆分管理）与 `deferred`（明确缓行）。
- 每条必填：canonical ID、名称、别名、范围、主要病种群、状态、仓库/包名、最后核验时间、来源版本、复用位置、负责人。

## 边界备忘

- 脑梗死不是并发症条目：它是用户 2026-11-18 定性的「第一个急症工作台」（慢病队列第 1 项、双重属性），其卒中专属症状/时效规则由原台负责；并发症台可复用其急症安全壳与交接组件概念，但不得复制其内容、不得取代其定位。
- 患者版安全口径（全条目通用）：先急诊后记录、安全出口首屏可达、不诊断、不输出分诊分数/低风险结论、不给用药建议；指南阈值转译为患者语言前须临床审阅与地区适配。
- 最后核验时间：2026-11-18（初版建立，来源为评估报告初筛；发生率数字多数未取得，指南 2026 现行版本状态待逐项复核）。
