# OpenHarness DSH Plugins\n\n为肿瘤患者、罕见病患者和慢性病患者提供AI赋能的决策支持平台\n\n## 📋 项目概述\n\nOpenHarness DSH Plugins 是一个基于共享决策管理（Shared Decision Management）理论的医疗支持框架和插件生态系统。我们致力于通过AI工具的能力加持，帮助患者和家属更好地与医疗专业机构和医生合作，获取资料受益，少走弯路。\n\n### 核心目标\n\n1. **框架与插件汇总**\n   - 为肿瘤患者、罕见病患者和慢性病患者提供完整的Harness框架\n   - 汇总和管理各类医疗支持插件应用\n   - 支持持续贡献和社区驱动的插件开发\n\n2. **共享决策支持**\n   - 基于SDM理论，赋能患者和家属做出更好的医疗决策\n   - 整合AI工具能力，提供个性化的信息和建议\n   - 促进患者、家属与医疗专业人员的协作\n\n3. **全周期覆盖**\n   - **早期筛查**：疾病风险评估和预防建议\n   - **确诊阶段**：诊断信息和治疗方案比较\n   - **临床治疗**：治疗过程支持和副作用管理\n   - **综合治疗**：多学科综合施策\n   - **心理营养**：心理健康和营养支持\n   - **安宁疗护**：生命末期护理和症状管理\n   - **哀伤管理**：失去亲人后的心理支持\n\n## ✨ 主要特性\n\n- 🏥 **多疾病覆盖**：肿瘤、罕见病、慢性病等\n- 🤖 **AI赋能决策**：基于最新医学知识的智能建议\n- 🔌 **可扩展插件系统**：支持社区贡献和自定义插件\n- 📚 **循证医学基础**：所有内容基于医学证据\n- 👥 **以患者为中心**：强调患者参与和共享决策\n- 🌍 **开源社区**：欢迎全球开发者和医学专家贡献\n\n## 🚀 快速开始\n\n### 系统要求\n- Node.js 14+ 或 Python 3.8+\n- Git\n- 现代浏览器\n\n### 安装\n\n```bash\n# 克隆仓库\ngit clone https://github.com/xyb-openharness-dsh-plugins/framework.git\ncd framework\n\n# 安装依赖\nnpm install\n# 或\npip install -r requirements.txt\n\n# 启动开发服务\nnpm run dev\n```\n\n### 基础使用\n\n```javascript\n// 示例：加载疾病支持插件\nimport { loadPlugin } from '@openharness/core';\n\nconst cancerPlugin = await loadPlugin('cancer-support-v1');\nconst decision = await cancerPlugin.analyzeCase({\n  diseaseType: 'breast_cancer',\n  stage: 'stage_2',\n  patientProfile: { age: 45, comorbidities: [] }\n});\n```\n\n## 📦 插件生态\n\n### 官方插件\n\n| 插件名称 | 功能 | 目标人群 | 状态 |\n|---------|------|--------|------|\n| Cancer
