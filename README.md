## 项目概述
OpenHarness DSH Plugins 是一套面向医疗/健康领域的插件集合，旨在通过 AI 提供诊疗路径支持、共享决策辅导和个性化随访建议，帮助肿瘤、罕见病与慢性病患者及其临床团队做出更好的决策与管理方案。

本项目以“公益与开源”为核心，面向研究者、临床工程师与开发者开放，致力于构建安全、可解释且临床可用的插件生态。

---

## 主要功能
- AI 驱动的共享决策支持（DSH）插件框架
- 病例抽取与结构化（文本/影像/检查项）
- 风险评估与个性化推荐模块
- 可扩展的插件机制（便于第三方接入）
- 多语言支持与本地化文档

---

## 设计目标
- 可解释性：输出带有支持性证据与参考来源
- 安全合规：隐私优先，避免可识别信息泄露
- 可扩展性：模块化插件，易于集成新模型与数据源
- 社区导向：鼓励临床、研究与开发者共同参与
